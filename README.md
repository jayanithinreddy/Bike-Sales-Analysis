# 🚴 Bike Sales Analysis | Excel, MySQL & Power BI

## 📌 Project Overview
This project focuses on analysing bike sales customer data to understand customer purchasing behaviour and identify patterns among customers who purchased and did not purchase bikes.

The project uses MySQL for data analysis and Power BI to create an interactive dashboard with meaningful business insights.

## 🛠️ Tools & Technologies
- **Dataset:** CSV
- **Database:** MySQL
- **Visualization:** Microsoft Power BI
- **Language:** SQL
- **DAX:** Data Analysis Expressions

## 📊 Key Performance Indicators (KPIs)
- Total Customers
- Bike Purchases
- Non-Purchases
- Purchase Rate
- Average Income
- Average Age

## 🔍 Analysis Performed
- Analysed bike purchases based on gender.
- Studied customer purchasing behaviour by education.
- Analysed customers based on commute distance.
- Compared purchasing behaviour by home ownership.
- Examined customer income and age.
- Analysed customer distribution across different regions.
- Used slicers for interactive data filtering.

## 📈 Power BI Dashboard

The dashboard provides an interactive view of customer purchasing behaviour through KPI cards, charts and slicers.

## 🎯 Project Objectives
- Understand customer purchasing patterns.
- Identify customer segments based on demographics.
- Analyse factors associated with bike purchases.
- Develop interactive business intelligence reports.
- Practise SQL and Power BI skills through a real-world-style project.
